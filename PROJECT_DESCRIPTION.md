# Project Description

**YouTube / Instagram Downloader** is a Python desktop application for downloading accessible video content from supported YouTube and Instagram URLs through a graphical PySide6 interface.

The project uses **yt-dlp** as its media backend and is structured with separate UI, service, worker, model, utility, configuration, and testing layers.

This repository contains the supplied project source code. The application source itself has not been intentionally modified for publication; repository work is limited to organizing the supplied source and adding documentation.

**Primary technologies:** Python, PySide6, yt-dlp, Pillow, pytest, FFmpeg.

**Project context:** Independent software-engineering / computer-vision student project.

**Important:** Use the application only for content you are authorized to download and in accordance with the relevant platform terms, copyright rules, and applicable law.
